WebSpire

About WebSpire

Webspire is an event aimed at empowering undergraduates by connecting them with experienced professionals in the field of web development. The program unfolds in two stages: the first lays a strong foundation in web design and development principles, while the second delivers an immersive, full-day hands-on workshop focused on front-end development with React. In its second stage, WebSpire drew over 250 enthusiastic participants, equipping them with essential skills and practical experience to thrive both academically and in the tech industry.


Awareness session: Introduction to front-end web development

An introductory session aimed at familiarizing participants with the fundamentals of front-end web development. It laid the groundwork for the upcoming workshops by highlighting essential concepts, tools, and technologies used in modern web development.


Online workshop: To enhance your HTML/CSS and JavaScript knowledge.

A technical session designed to strengthen participants' HTML, CSS, and JavaScript skills. Delivered virtually, it allowed students to dive deeper into coding practices and enhance their understanding of core front-end building blocks.


Physical workshop: Dive deep into advanced JavaScript (ES6) and React.

An in-depth, hands-on workshop that focused on advanced JavaScript (ES6) and React. Conducted in person, this session provided a practical learning experience, helping attendees build dynamic web applications and apply their skills in real-world scenarios.
