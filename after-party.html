Microsoft Build After party

About the event

Microsoft Build After Party: Season of AI at IIT Sri Lanka brought together tech enthusiasts and industry professionals for an inspiring afternoon of innovation and learning. Organized by the Microsoft Student Ambassadors in collaboration with the IEEE Computer Society Student Branch Chapter of IIT, the event featured three insightful sessions centered around cloud computing, AI development, and modern deployment practices.


Mr. Sahan Dissanayaka

shared his expertise on Machine Learning Workflow Design with Cloud, offering a deep dive into scalable ML pipelines and cloud integration.


Mr. Indrajith Ekanayake

a Microsoft MVP and Cloud Native expert, demonstrated how to Deploy Containerized Applications using Azure Kubernetes Service, emphasizing efficiency and flexibility in modern app deployment.


Mr. Nandun Diaz

a Gold Microsoft Learn Student Ambassador, showcased how AI Development Can Be Streamlined with Azure AI Studio, highlighting tools that simplify and accelerate the AI development lifecycle.
