Postman API Workshops

About the event

Led by certified Postman Student Experts, these workshops organized by our chapter, offered a clear and practical introduction to Postman and API development. Centered around API development, these sessions offered hands-on, practical experience that helped participants understand how to build and test APIs effectively. With over 300 students taking part, the workshops served as a valuable stepping stone for students looking to strengthen their technical toolkit and advance in both academic projects and future tech careers.


Introduction to APIs using Postman


Led by Postman Student Expert Hasala Abhilasha, this virtual session introduced students to the fundamentals of API development and testing using Postman. With no prior experience required, attendees gained hands-on exposure to API requests, responses, and workflows, laying the groundwork for modern software integration skills.


API 101 Using Postman


Facilitated by Postman Student Expert Geesad Bandara, this beginner-friendly session guided students through the basics of APIs using Postman. Participants explored how to send requests, interpret responses, and build a strong foundation in API testing, with no prior experience required.
